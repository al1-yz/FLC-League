# We define our own Archetype taxonomy instead of Riot's classes

Archetypes follow a community-style list we maintain (`docs/domain/archetypes.md`), not Riot's official classes or Data Dragon `tags`. Riot's system has no "Control Mage" (Orianna is officially a Burst mage) and does not split marksmen by lane style, so it can't express the comparisons the user wants. Consequence: classifying a new champion is a manual curation step; Data Dragon tags are not used for Archetype Matchup figures.
